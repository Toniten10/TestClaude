# Hello World

Página estática sencilla lista para desplegar en Netlify.

## Despliegue en Netlify

1. En Netlify, elige **Add new site → Import an existing project** y conecta este repositorio.
2. Netlify lee `netlify.toml` automáticamente: no hace falta comando de build y el directorio publicado es `public`.
3. Pulsa **Deploy**.

También puedes arrastrar la carpeta `public` a https://app.netlify.com/drop.
